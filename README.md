# 📝 Tech Blog (Next.js)

A blog application built with **Next.js 14+ (App Router)**.  
It supports **multilingual content** and advanced **SEO optimization**, including:

- `metadata`
- `JsonLd`
- `sitemap.xml`
- `generateStaticParams`
- `alternates`
- `dir` attribute

The project follows the modern `src/app` structure.  
Users can browse posts and view author details.

## 🔧 Technologies Used

- **Next.js 14+** (App Router, `src` structure)
- **TypeScript**
- **Redux Toolkit**
- **Tailwind CSS**
- **SEO features** (metadata, JsonLd, sitemap, alternates, dir attribute)
